# 🌤️ Weather Info Dashboard

![React](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)
![OpenWeatherMap](https://img.shields.io/badge/API-OpenWeatherMap-FF6F00?style=for-the-badge&logo=openweathermap&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![Responsive](https://img.shields.io/badge/Responsive-Yes-brightgreen?style=for-the-badge)

> A beautiful React-based weather application that fetches real-time weather data from OpenWeatherMap API. Search any city worldwide and get current weather conditions with dynamic backgrounds that change based on the weather!

## 📱 Features

| | Feature | Description |
|---|---------|-------------|
| 🔍 | **City Search** | Search any city worldwide for current weather |
| ⏳ | **Loading States** | Smooth spinner animation while fetching data |
| ⚠️ | **Error Handling** | Proper messages for invalid cities, network issues, empty input |
| 🎨 | **Dynamic Backgrounds** | Background changes based on weather (clear, rain, clouds, etc.) |
| 📱 | **Responsive Design** | Perfect on mobile, tablet, and desktop |
| ✨ | **Glass Morphism UI** | Modern, frosted glass effect with background shapes |

## 🌈 Dynamic Backgrounds

| Weather Condition | Background | Visual |
|-------------------|------------|--------|
| ☀️ **Clear Sky** | Warm gradient | `linear-gradient(135deg, #f6d365, #fda085)` |
| ☁️ **Clouds** | Cool gradient | `linear-gradient(135deg, #bdc3c7, #2c3e50)` |
| 🌧️ **Rain** | Blue gradient | `linear-gradient(135deg, #00c6fb, #005bea)` |
| ⛈️ **Thunderstorm** | Dark gradient | `linear-gradient(135deg, #373b44, #4286f4)` |
| ❄️ **Snow** | Light gradient | `linear-gradient(135deg, #e6e9f0, #d0d9e0)` |
| 🌫️ **Fog/Mist** | Soft blur | `linear-gradient(135deg, #757f9a, #a3b1c6)` |
| 🎯 **Default** | Blue gradient | `linear-gradient(135deg, #62b8f5, #4475ef)` |

## 🚀 Quick Start

# Clone repository
git clone  https://github.com/beingtaha/Weather-Dashboard_Appverse-Internship-Project-.git

# Install dependencies
cd Weather-dashboard_Appverse-Internship-Project
npm install

# Start development server
npm start

# Open in browser
http://localhost:3000

---

## 🧠 Key Learnings

✅ API Integration: Fetching data from OpenWeatherMap with proper error handling.

✅ State Management: Multiple useState hooks for different UI states.

✅ Loading States: Spinner animation during async operations.

✅ Error Handling: Try-catch blocks with user-friendly messages.

✅ Dynamic Styling: CSS classes based on API response.

✅ Responsive Design: Media queries for all devices.

✅ Glass Morphism: Modern UI with backdrop-filter.
